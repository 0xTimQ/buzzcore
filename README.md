# BUZZCORE · THE SYNDICATE

Native 1536×1920, 60 fps cinematic renderer for tim777. 31.9 seconds, 1914 frames.

## Run
Node.js 20+ and FFmpeg on PATH. `npm install`, then `npm run render`. `npm run stills` creates review frames. A finished MP4 is supplied separately.

## Characters and scene
TOMMY is the cartoon fly boss, inspired by Tommy Shelby. His nine friends are ARTHUR (scout), JOHN (holders), FINN (analysis), CHARLIE (filter), ABERAMA (liquidity), CURLY (risk), BONNIE (timing), ISAIAH (execution), and ALFIE (audit).

White BUZZCORE design, a pale 1920s Birmingham street, factory smoke, gas lamps, a rotating command halo, moving packet trails, wing animation, hover, active lamps and cigarette smoke. All nine agents remain visible. Created from one image-generation pass per asset, followed by a single final video render.

Character assets were made using the built-in image generator. Prompt summaries: a stylized 3D cartoon Tommy Shelby fly with icy blue eyes, flat cap, pinstripe suit and lowered cigarette; a 3-by-3 sheet of nine distinct male cartoon fly gangster friends in matching 1920s clothing. All character images have alpha transparency.

## Scope
This is an authored motion-design project, not a live trading application. PONS and the target profit were supplied by the project owner. Intermediate balances and activity logs are animation data, not a transaction export. No wallet connection or actual execution is implemented.

## Soundtrack
User-provided AVANGARD (Slowed + Reverb), excerpt 32.27–64.17 seconds, matched to the previous music level and attenuated during the risk check. Third-party audio is included for this private render and excluded by .gitignore; obtain the needed rights or replace it before public source distribution.
